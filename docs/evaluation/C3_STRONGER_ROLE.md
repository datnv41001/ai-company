# Qwen 7B matched-role comparison

The product qualification PR calls `.github/workflows/c3-stronger-role.yml` after its integration model job. It compares a 7B role response with the 0.5B response recorded for the same synthetic brief. WF-03 varies the strategy role and WF-13 varies the content role. The other roles and the Studio composer remain fixed. A reviewer can inspect the returned text, the changed fields and the structural findings. Semantic advantage, human approval and manual time savings require separate evidence.

## Inputs and results

The reusable workflow accepts the current GitHub integration SHA. It reads `pool-model-measurements-integration/c3-product-v2/<case>/paired-role.json` and its sibling `result.json` from the same GitHub Actions run. The reader checks the committed frozen-set digest, case and workflow, original request and output, projection, model SHA and composed fields before replay. Every baseline request retains its system instructions, user payload, schema, temperature and token cap. Both inference calls use the local gateway's seed of 42. No application database, customer or paid endpoint participates.

Download the artifact `c3-stronger-role-<integration-sha>`. `summary.json` lists each assigned case, input gaps, actual attempts, paired results, input and output tokens, runner hardware, elapsed inference time per role and kernel process peak RSS. Each measured case also includes its raw synthetic outputs and comparison in `<case>/result.json`. Examine the denominators, failures and unmetered attempts alongside positive pairs. The sentinel `docs/evaluation/c3-product-v2/RESULTS.md` closes the study on subsequent PR runs.

## Weights and operating budget

The official Qwen2.5-7B-Instruct Q4_K_M GGUF consists of two shards. The program pins revision `bb5d59e06d9551d752d08b292a50eb208b07ab1f`, verifies both full-file SHA-256 values and uses the same pinned llama.cpp server image and 8,192-token context as the baseline. The GGUF repository publishes the Apache-2.0 license. The standard public Ubuntu runner is free and offers 4 vCPUs, 16 GB RAM and 14 GB disk. The job measures available RAM and free disk before downloading. It budgets 4.7 GB for weights, 448 MiB of FP16 KV cache, 3 GiB for working memory and 3 GiB of extra disk for the image and workspace. The server has a 9 GiB memory ceiling. The study runs at most one inference per assigned case, ten calls total, with concurrency one, 640 completion tokens per call, a 110-second inference timeout and a 45-minute job deadline. A resource or integrity failure produces a checkpoint showing which results are available. No model weights are uploaded as artifacts.

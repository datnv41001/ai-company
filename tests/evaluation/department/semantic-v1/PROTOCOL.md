# Advisory comparison, frozen before inference

Base product eff86cda2f99dd10244dc8127451e941bb546a3c. An independent engineering AI authored the synthetic inputs and labels without seeing the candidate outputs. The evaluator receives both 60 main cases and 24 diagnostic cases, but keeps their labels out of inference, source projection and prompt development. The main split pairs English records with Vietnamese and English copy. The stress split uses Vietnamese records and declarative unknowns. Each includes twelve commercial categories. Publish results for each split and each language. These inputs have no real customer, study participant or third-party dataset.

Two prospective hypotheses:

1. A constrained local advisory read will identify more source-refuted claims than deterministic QA, with few additional false alarms. The deterministic arm invokes the production C3 span classifier with precision enabled. The projection splits the supplied record into sentences, recognizes stated VND amounts and labels hypothesis statements. Complete multi-field production snapshots, brand exclusions and reviewer resolutions are outside this text-pair test. Only a definite contradiction counts as the positive class. A correction with insufficient proof, missing result or unresolved format counts as abstention. Unknown is an abstention even when a human would correctly call a claim undecidable. A supported prediction by the model requires an exact source quote and remains advisory. The composite keeps every definite baseline decision and takes the model suggestion only on abstentions. Publish confusion matrices against all three labels. Count contradictions that are abstained on as missed for recall. Report false positives on gold supported cases, false positives on gold non-contradicted cases, unknowns guessed supported, and total abstentions. A quote substring validates provenance only. Model votes never modify an AMC decision.
2. Adding a task-specific AI proposal to a deterministic campaign pack will contribute grounded, usable detail on two new briefs. Compare the production pack fields for research, positioning/strategy, social, organic search, media and creative to one proposed revision per role/brief. Both arms get the same synthetic facts. Read every output against real brief needs and record concrete additions, wrong or missing terms and editing needed. Separate technical observation by an AI from expert signoff. Unmeasured correction time stays unknown.

**Decision rule.** No runtime promotion on this test alone. Reconsider a larger independent pilot if advisory triage improves recall in both splits, adds at most one false contradiction per split and never labels a gold contradiction as supported. Professional adoption also requires lower human editing/QA effort or improved first-pass acceptance at known cost. Specialist findings select individual follow-up tasks; they never promote a whole role or workflow.

**Budget and custody.** A single pinned Qwen2.5-1.5B Instruct Q4_K_M CPU instance, 84 semantic calls at up to 80 output tokens each plus 12 specialist calls at up to 192 tokens each. Concurrency one, temperature zero, seed 42, no tools, no retries for poor answers. Save the unmodified request and response to separate per-call checkpoints, plus timings, token usage, hashes and both original outputs. Archive predictions before opening the separately held labels. Never send text to an external inference service. The optional model is run only within this engineering experiment.
